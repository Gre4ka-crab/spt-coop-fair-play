# PrivateStack Fair Play 0.2.0 — QA

Это кандидат для SPT 4.1.6 / EFT 40743, Fika Core 2.4.5 / Server 2.4.2.
Игровая приёмка ещё не выполнена. Серверный QA-компонент установлен по запросу
владельца; stable не переключён. Для сервера 0.2.0 требуется клиент 0.2.0.

Кнопка создания рейда отключена, пока сервер не подтвердил хотя бы один свободный
headless. Список обновляется асинхронно каждые 2,5 секунды; подтверждение старше
5 секунд не разрешает запуск. Ошибка сети сразу блокирует создание. Штатный экран
сохраняется: счётчик доступных экземпляров, заблокированный локальный режим,
выбор одного из нескольких headless. При двух свободных требуется явный выбор.
Выбор сохраняется по идентификатору, а не номеру строки; исчезновение выбранного
экземпляра не переносит запрос на другой автоматически.

Перед отправкой запуска выполняется новая проверка выбранного headless. Подключение
requester WebSocket не блокирует Unity main thread; после подключения доступность
проверяется повторно. Backend атомарно резервирует выбранный экземпляр и запрещает
двойной запуск от одного инициатора. Занятые/зарезервированные экземпляры и закрытые
WebSocket не выдаются как свободные. Стандартные transport/WS/проверки модов Fika
сохранены. Готовность означает состояние процесса Fika, не гарантию загрузки карты.

Проверка списка/соединения ограничена 8 секундами, ожидание ответа запуска — 30.
Потерянное подтверждение не считается гарантированным отказом: автоматической
повторной отправки и переключения на другой headless нет. Нужно вернуться в меню,
проверить сервер и снова выбрать экземпляр. Сервер сохраняет неопределённую
резервацию до штатного Reset/reconnect headless; аддон не останавливает чужой рейд.
Пока реально работает один headless. Два процесса/GUI/co-op требуют отдельной
игровой приёмки; fixtures двух записей не считаются двумя настоящими процессами.

Исправлено: отказ от локального хоста происходит до включения загрузочного экрана.
Плашка отказа исчезает через 10 секунд либо перед разрешённым запуском headless.
Ошибка проверки политики остаётся видимой и продолжает блокировать подключение.
Для обновления полностью закройте игру: DLL уже запущенного клиента не обновляется.

Аддон запрещает штатное локальное создание рейда и включает Auto Use Headless.
При недоступном headless переход на локальный хост запрещён. Backend-компонент
отдельно допускает создание рейда только настроенным headless с открытым websocket
и совпадающим ServerId/session. Выбор карты и обычного day/night сохраняется.
AI рассчитывают моды на headless; обработка персонажа, оружия и часть сетевой
симуляции остаются в архитектуре Fika. Полного переноса всех расчётов здесь нет.

Клиент фиксирует и скрывает 83 настройки Dynamic Maps, 58 настроек Fika,
138 UI Fixes и 23 All Quests Checkmarks. Изменение cfg до запуска не становится
новой базой. Фиксированные значения встроены в DLL: по умолчанию берутся defaults
именно закреплённых DLL, для UI-модов — ранее подготовленные конфиги проекта.
У карты сохраняются 9 прежних ограничений: нет врагов/своего маркера, автоэтажа,
автоцентрирования, peek и миникарты. Дополнительно выключен Dump Info Hotkey.
Прочие возможности карты, включая дружеские маркеры, сохраняют defaults.

Настройки Fika Network, служебная Hidden, звуковые настройки WTT и необязательная
Amands Graphics остаются пользовательскими. Это конечный список проверенных модов,
а не автоматическое распознавание любой настройки будущих модов. Обычные настройки
игры/графики/управления не блокируются. Координатный текст Player:x/y/z в самой
карте пока не скрывается: у установленной версии нет соответствующей настройки.

Backend закрывает редактор рейда, freecam и наблюдение за ботами. Параметры запроса
заменяются серверной политикой: AI amount/difficulty AsOnline, bosses=true,
scav wars/tagged=false, metabolism disabled=false, spawn DifferentPlaces,
custom weather/disable overload/disable stamina=false, event=false.
TimeAndWeather устанавливается HourOfDay=-1 (штатное выбранное время), TimeFlow=x1.
Ранее 0.1.0 принудительно задавал полдень; это отдельное исправление, не доказанная
причина зависания карты. QB/SAIN/LB сохраняют свою
настройку на headless. Неизвестные расширения верхнего raid DTO отклоняются.

Проверка модов дополнена требованием точного CRC32C этого аддона у человека.
На headless аддон запрещён и не требуется. Глобальные Fika required/optional
массивы не заменяются; результаты проверки всех остальных модов сохраняются.
Клиентские hashes и флаги не являются защищённой аттестацией: владелец компьютера
может переписать клиент и подделать обмен. Это ограничение штатных функций и
единых правил частного кооператива, не полноценный античит. Backend не начинает
доверять клиенту расчёт AI из-за наличия аддона.

## Установка на тестовый игровой ПК

Сначала установите прежний комплект client-deploy-c3289b8fe888f225 или его точную
135-file closure. Этот ZIP содержит только собственный аддон, без чужих DLL и игры.
Python 3.11+ и PowerShell 7 должны быть установлены. Закройте игру и лаунчер.

```powershell
pwsh -File .\Install-Addon.ps1 -Target 'D:\Games\SPT'
pwsh -File .\Install-Addon.ps1 -Target 'D:\Games\SPT' -Apply
pwsh -File .\Install-Addon.ps1 -Target 'D:\Games\SPT' -Action Verify
```

Без -Apply выполняется только план. Проверяются EFT file version, отдельная SPT
установка, отсутствие HeadlessConfig и запущенных целевых процессов, все точные
зависимости и отсутствие hardlink/reparse. Неизвестная изменённая DLL сохраняется
с BLOCKED. Устанавливаются только DLL и её LICENSE, плюс receipt в
BepInEx/.clientfairplay. Перед установкой отдельно копируются 4 существующих cfg.
Снимки конфигов приватны и не входят в клиентский ZIP.

Backend-компонент FairPlayServer.dll распространяется отдельно среди artifacts.
Проверки backend/API выполнены отдельно; GUI/настоящий клиент ещё требуют приёмки.
В client ZIP backend и headless компоненты не входят.
Пока backend-компонент не установлен, клиентский запрет можно обойти удалением DLL.
Даже после установки backend проверяет правила хостинга, но не обеспечивает
криптографическую подлинность удалённого клиента.

## Откат

Путь backup выводится после Install. Укажите transaction.json ровно этой операции:

```powershell
pwsh -File .\Install-Addon.ps1 -Target 'D:\Games\SPT' -Action Rollback -Journal 'D:\Games\SPT\BepInEx\.clientfairplay\transactions\<id>\transaction.json'
pwsh -File .\Install-Addon.ps1 -Target 'D:\Games\SPT' -Action Rollback -Journal 'D:\Games\SPT\BepInEx\.clientfairplay\transactions\<id>\transaction.json' -Apply
```

Откат восстанавливает только файлы операции; изменённые после установки файлы
не перезаписываются. cfg автоматически не откатываются: их snapshots сохранены
отдельно, чтобы не затереть дальнейшие личные изменения. После удаления аддона
backend будет показывать missing required addon, пока владелец не откатит также
серверный компонент. Не выключайте всю Fika validation.

## Приёмка перед stable

1. LAB backend/headless стартуют с штатной validation; addon не нужен headless.
2. Human startup без ошибок схемы; в F12 нет контролируемых настроек; Network работает.
3. Переписанный cfg не включает врагов, своё положение, миникарту или debug dump.
4. Нет headless → понятный отказ без локального хостинга. Готовый headless → рейд.
5. Native HTTP create от обычного session отклонён; запрос со stamina/AI/weather
   overrides не меняет серверную политику. Подмена ServerId не создаёт рейд.
6. Удалённый или изменённый addon вызывает native missing/hash mismatch;
   чужие запрещённые/несовпадающие моды по-прежнему отклоняются.
7. Человек PMC/scav, day/night, обычный переход, 2/4 co-op и rollback проверены в игре.

Сборка и fixtures не заменяют эти проверки. Здесь они PENDING/BLOCKED.

Исходники и проверки находятся в src/ClientFairPlay, src/FairPlayServer,
tests/ClientFairPlay.Tests, tests/FairPlayServer.Tests, tests/FairPlayNative.Tests.
Зависимости сохраняют свои лицензии; они не перепубликуются этим ZIP.
